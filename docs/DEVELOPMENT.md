# 开发与验收

首次公开发布流程见 [GitHub 与 Obsidian 社区上架指南](PUBLISHING.zh-CN.md)，包括无旧 Git 历史的初始快照、双语 README、许可证、Release 附件及账号绑定。公开名称为 Read & Return，ID 为 read-and-return。

## 工具链

Node.js 22、npm、TypeScript、esbuild、Obsidian SDK、tsx 和 Node 内置测试运行器。锁文件固定安装解析结果。开发依赖不进入 release。

```sh
npm ci
npm run build
npm test
npm run release
```

`build` 执行严格类型检查并生成根目录 `main.js`。`dev` 启动构建监听但不执行类型检查；交付前必须运行 `release`。`release` 先生产构建和测试，再校验版本映射，生成 `release/<version>/read-and-return/`。打包逐文件覆盖并校验字节一致性，打印变化和 SHA256；发现意外文件会停止，不擅自删除用户文件。

更新版本时同步 `package.json`、`package-lock.json`、`manifest.json`、`versions.json` 和 changelog。构建 banner 从 manifest 获取版本。旧版 release 目录可保留，新版本放入新的版本目录。

## 自动化

`tests/navigation.test.ts` 验证上下文、重复段落、插入/删除、空文档、围栏标题、末行小数、降级策略、前进/后退分支、边界、重命名与淘汰。适配器测试模拟 Reading View 和 editor，不运行真实渲染引擎。

`tests/plugin.test.ts` 将实际入口打包，在只读宿主替身中执行命令、顶部/底部/返回、重复边界操作、底部失败及长笔记底部菜单操作、返回失败、文件事件、卸载及无笔记状态。另覆盖语言选择/英文回退、菜单及清除命令可用状态。阅读宿主替身明确区分不滚动的外层容器与内部正文滚动区域；长笔记底部菜单用例在 0.1.3 逻辑下失败，修复后通过。适配器另覆盖容器自身即滚动区域、容器缺失和高度为零、内部滚动比例捕获与恢复。不会创建真实 Obsidian 窗口。

长笔记测试使用 84,003 行、2,664,583 字节的 Markdown，包含中文段落、重复文本、标题、表格、列表和围栏代码。在第 2700 节保存位置并在文件前部插入内容，验证后半部返回位置。宿主性能与移动设备速度仍需实测。

## 生成真实长度的手工验收文件

```sh
npm run fixture
```

会生成 `.qa/long-note.md`（不提交、不打进插件包）。将其复制到测试仓库；这是一份程序生成的长 Markdown 样本，还应补测自己的真实资料，尤其包含异步图片、嵌入或大型表格的笔记。

## 宿主验收流程

分别在 Desktop Reading View、Desktop Live Preview、Desktop Source Mode、Mobile/iOS Reading View、Mobile/iOS editor 执行以下步骤，并记录 Obsidian 版本、设备、主题和结果：

1. 从 release 安装并启用。确认命令和设置正常；手机显示悬浮按钮，桌面默认隐藏。
2. 在长笔记后半部滚动，使输入光标与可见位置不同。点击顶部、返回，应回到阅读位置而非光标。
3. 特别复测手机阅读视图的笔记中段，不能错误提示“已在底部”。从 ⋯ 选择“跳转到底部”，确认末行完整可见、主按钮变为 ↩，点击返回应恢复来源位置；重复底部操作不能覆盖原返回点。测试末行超长段落、空笔记、短笔记和异步嵌入。在顶部重复执行顶部，再返回，原点仍有效。测试首行/末行超长段落和空笔记。
4. 设置返回点，在其他位置继续阅读，再返回；重复 A → 顶部 → 返回，测试后退、前进、手动滚动后的前进，以及新分支清除前进记录。
5. 保存返回点后，在之前插入/删除数百行并切换阅读/编辑模式，再恢复。删除原段落验证近似恢复提示。
6. 改字号、改窗口宽度、旋转手机、折叠/展开章节、等待图片与嵌入加载，记录位置偏差。
7. 切换笔记/窗格，重命名文件和文件夹、移动或删除，验证不会混用记录。
8. 选择/复制文字、正常滚动、打开软键盘、左右切换按钮及调整底部间距，确认不干扰核心操作。移动端特别复现 `references/20261016/01.jpg` 的底部悬浮导航栏：保留旧的 24px 设置，在导航栏显示/隐藏、横竖屏及阅读/编辑模式下确认控件可完整点击；检查设置显示有效 96px，调至 160px 后位置进一步上移。桌面仍使用旧底距。
9. 禁用/重启插件，确认控件清除且导航状态消失，设置保留。
10. 分别以简体中文、繁体中文、英文和其他语言启动插件，检查菜单没有重复箭头、文案只有一种语言，设置、按钮提示和通知同步；仅简体中文显示中文，繁体中文及其他语言均显示英文。更改宿主语言后重新加载插件。无记录时返回/后退/前进/清除禁用，顶部及返回之后检查历史和清除仍可用。
11. 在仅执行导航的步骤前后比较测试 Markdown 的 SHA256，正文必须一致。
