# 数据模型

## 临时位置

`Position` 保存：

| 字段 | 含义 |
| --- | --- |
| `line` / `fraction` | 视口顶部的源码行及行内小数位置，不是输入光标 |
| `text` | 所在行的修剪后文本，最多 240 个 UTF-16 字符 |
| `before` / `after` | 前后相邻行的同样长度片段 |
| `heading` | 最近的 ATX 标题文本，忽略围栏代码内标题 |
| `headingOffset` | 相对于标题的行偏移 |
| `ratio` | 滚动范围内的比例，限制在 0–1 |

每次恢复先评估文本候选，比较相邻文本和标题，距离原行较近作为同分优先因素。完全相同文本可直接命中原位置；正文上方插入或删除行后，候选位置可随文本移动。空白行需要至少一个非空相邻上下文匹配。

恢复顺序：文本上下文 → 同名标题及原相对偏移 → 仍在范围内的原行 → 滚动比例。上下文未命中时显示近似恢复提示。同名标题选择距离旧位置较近者；Setext 标题没有专门建模，仍可通过普通文本上下文匹配。多个完全相同的长段落、改写行尾且前 240 字相同等情况存在歧义。

## 会话

`SessionStore` 按笔记路径维护最多 100 个 `NoteSession`，采用最近使用顺序淘汰。每个 session 包含一个 `returnPoint` 及各最多 50 项的 `back` / `forward` 栈。

- 底部操作：保存来源位置，推入后退栈，清空前进栈；已在底部或笔记无需滚动时不覆盖返回点、不添加历史。仅在滚动调用成功后提交会话变化，与顶部操作一致。
- 顶部操作：保存来源位置，推入后退栈，清空前进栈。已在顶部时不覆盖返回点。
- 设置返回点：覆盖旧返回点，并将当前位置作为历史检查点，清空前进分支。
- 返回：恢复返回点，将离开的位置加入后退栈，清空前进栈，消耗返回点。
- 后退/前进：先查看目标；滚动调用成功后才从对应栈取出目标，将当前点加入另一栈。
- 普通滚动不记历史；执行历史操作时实时捕获当前视口，因此仍可前进回到离开的实际位置。
- 连续近似相同的位置去重；历史目标如果与当前位置相同，会继续查找更早目标。
- 切换笔记不混合历史。同一笔记的多个窗格共享会话，命令作用于当前活动窗格。
- 文件/文件夹 rename 事件按完整路径或目录前缀迁移；delete 事件清除对应记录。

会话重启即清空，不做跨重启导航迁移，也不存储笔记内容副本或永久书签。

## 插件数据

只有设置调用 `saveData`，保存到 Obsidian 管理的插件数据文件：

```json
{
  "schemaVersion": 1,
  "settings": {
    "mobileControl": true,
    "desktopControl": false,
    "side": "right",
    "bottom": 24
  }
}
```

缺失数据使用默认值；无效字段按类型检查及范围限制修正。未知版本使用默认设置，不主动覆盖数据，除非用户之后修改设置。v0.1 没有旧版本需要迁移；后续增加持久位置时应升级 schema 并提供显式迁移。

v0.1.1 不改变 schema 或已有底距值。移动端展示时将有效底距限制为至少 96px，之后再叠加安全区；移动端设置滑块也显示这一有效值。桌面仍使用已保存的原值。只有用户调整设置时才写回数据。
